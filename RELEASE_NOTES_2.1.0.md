# KiCad Track Gloss 2.1.0 — Smart Octo test release

- One effective irregular octolinear obstacle is built from the maximum of the
  moving-net clearance, obstacle clearance and applicable KiCad floors.
- Clearance provenance remains visible without duplicating solver geometry.
- Track, via, round and pad obstacles share the Smart Octo contact model.
- Interior translation, T sliding, fixed-point passes and best-incumbent timing
  remain general continuous operations, not geometry patterns.
- A separate action toggles a grouped diagnostic overlay on an unused `User.*`
  layer. It shows source envelopes and the effective polygon and is removable
  in one command.
- The historical Real Spirit package name and candidate-geometry module are
  removed from production code.
